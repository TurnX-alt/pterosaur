# Spec — 封面缓存 7 天过期

对应模块：`web/lib/mediaCache.ts`、`web/sw.ts`、`web/components/SettingsDialog.tsx`

## 要构建什么

- 目标：让封面缓存（与音频共用 16GB IDB 池）与「应用外壳 7 天过期」对齐——**缓存 7 天后自动过期**，到期后回源刷新。
- 交互形态：无新增界面；设置弹窗缓存段文案补一句「封面另在 7 天后自动过期」。

## 行为

- 预期行为：
  - 封面写入 IDB 时记录 `cachedAt`（写入时刻）。
  - SW 命中封面时：若 `now - cachedAt ≥ 7 天` → 清除该条目并按**未命中**回源重取、写回；否则正常返回并刷新 `lastAccess`。
  - SW 启动（`loadState`）时清扫一遍过期封面，避免长期占用预算。
  - 音频：`kind === 'audio'` **不过期**，仅受 LRU 淘汰。

## 输入 / 输出

- 输入：`<img>` 对封面地址的请求；SW 生命周期（activate）。
- 输出：封面响应（命中即返、过期则回源重取）；IDB 中被清除的过期条目。

## 约束

- 过期判定为**纯函数**（`isExpired` / `expiredKeys`），可单测且被 `sw.ts` 复用。
- 固定 TTL（从写入时刻起算），非滑动窗口。
- 缺 `cachedAt` 的旧数据视作 `0` → 判为过期 → 首次访问平滑刷新（无需迁移）。
- 与音频共享同一 LRU 预算不变（跨类别按 `lastAccess` 淘汰）。

## 边界条件

- 音频条目：永不过期，不受本规则影响。
- 旧封面（无 `cachedAt`）：判为过期，回源刷新一次后带上 `cachedAt`。
- 恰好满 7 天（`now - cachedAt === IMAGE_TTL_MS`）：判为过期（边界为 `≥`）。
- 回源失败：按既有逻辑回退直连且不缓存，功能不受损。
