# PRD — Pterosaur 网页音乐播放器

## 产品目标

- 让用户打开网页即可搜索、发现并畅听音乐，**无需注册或登录本应用**。
- 提供接近 Apple Music 的播放体验：流畅的发现流、沉浸的全屏播放页、逐行同步歌词、完整的播放控制。
- 为愿意登录网易云账号的用户解锁 VIP 曲目，会话仅保存在其本机浏览器。

## 用户与使用场景

- 目标用户：想在浏览器里听歌、不愿装客户端、不想为「随便听听」注册账号的普通用户；以及拥有网易云 VIP、希望在自托管播放器里用自己会员权益的用户。
- 典型场景：
  - 打开首页，浏览推荐歌单，点一首就开始听。
  - 搜索「陈奕迅 我们」，点击结果播放，切到全屏看歌词。
  - 把喜欢的歌加红心收藏，或新建本地歌单整理。
  - 登录网易云后播放此前无法播放的 VIP 曲目。
  - 用键盘快捷键（空格播放/暂停、←→ 快进快退、N/P 切歌）盲操作。

## 核心问题

- 浏览器不能直连网易云音频：真实音频地址是 `http://` 且接口无 CORS，直接在页面请求会被混合内容与跨域策略拦截。
- 免登录无法播放 VIP/付费曲目。
- 老项目只能靠手动输入歌曲 ID 添加，没有搜索与发现能力，体验远落后于主流音乐应用。

## 功能及其意义

| 功能 | 解决什么 | 为什么需要 |
|------|----------|------------|
| 后端音频代理（同源 + https 改写 + Range） | 浏览器无法直连网易云音频 | 这是「能出声」的前提，没有它前端拿不到可播放的音频流 |
| 搜索 | 用户不知道歌曲 ID | 让「想听什么就搜什么」成立，是最核心的入口 |
| 发现（推荐/精品歌单/排行榜） | 不知道听什么时有内容可逛 | 对齐 Apple Music「立即收听/浏览」，提升留存与探索 |
| 电台（随机播放） | 想要「不挑歌」的伴随式收听 | 低成本提供无限流体验 |
| 歌单详情 | 点进合集要能看到并播放全部曲目 | 发现流的落地页，承接播放 |
| 全屏播放页 + 逐行同步歌词 | 播放时缺少沉浸视觉与歌词 | Apple Music 体验的标志性部分，点歌词可跳转 |
| 播放控制（播放/暂停/上下曲/进度/音量） | 基础听歌操作 | 播放器立身之本 |
| 播放队列 | 看不到、管不了待播列表 | 支持查看、跳播、移除、清空，掌控播放顺序 |
| 循环 / 随机模式 | 听完一首后的续播策略 | 覆盖单曲循环、列表循环、随机等主流习惯 |
| 收藏（我喜欢的音乐） | 想留住喜欢的歌 | 高频刚需，本地持久化，免登录也能用 |
| 最近播放 | 想回到刚听过的歌 | 免登录的轻量历史，提升复访 |
| 本地歌单 | 想自己整理曲目集合 | 无需云端账号即可建单、加删曲目 |
| 网易云登录（扫码/手机号） | VIP 曲目免登录播不了 | 解锁完整曲库；会话只存浏览器 cookie |
| 明暗主题 | 不同环境下的观感偏好 | 跟随系统或手动切换 |
| 键盘快捷键 | 高频操作的效率 | 无需鼠标即可控制播放 |
| 播放受限提示 | VIP/版权曲目播不了时用户困惑 | 明确告知原因并提供「登录解锁」入口 |

## 功能之间的关系

- 「后端代理」是所有播放能力的地基：搜索、歌单、电台最终都通过它把曲目交给音频引擎播放。
- 「发现 / 搜索 / 电台」是三条并列的内容入口，最终都汇入同一套「播放队列 + 播放控制 + 全屏播放页」。
- 「收藏 / 最近播放 / 本地歌单」构成资料库，既能在首页快捷入口露出，也能作为播放源。
- 「网易云登录」横跨全局：登录后 VIP 曲目可播、可拉取「我的歌单」，未登录时相应能力优雅降级并给出提示。

## 范围与非目标

- 范围内：网页端的发现、搜索、播放、歌词、队列、资料库、网易云登录与 VIP 解锁；可安装的 PWA（应用外壳与已播放音频 / 封面的本机缓存，外壳缓存 7 天过期）；歌单 / 专辑打包下载。
- 范围外：
  - 纯静态部署（必须有 Node 后端）。
  - 自建音源、音频转码。
  - 多用户账号体系、云端歌单同步、社交/评论/分享。
  - 移动端原生 App、桌面客户端。
